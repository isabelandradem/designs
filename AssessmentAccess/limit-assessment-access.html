Engineering PRD

Limit Assessment Access to School Hours

Problem

Teachers and administrators need assessment results to reflect what students can do in a controlled classroom setting with teacher supervision. When students complete assessments at home, they may receive help from a parent or caregiver, which can make the results less reliable.

Proposal

Add a new teacher setting that limits when students can access assessments.

The setting is on by default, with the default access window set to 7:00 AM–3:00 PM, Monday through Friday. Teachers can customize the start and end times.

Mockup · Teacher Settings, Web Dashboard

The updated Settings page adds a new Class Preferences row.

The new row includes an on/off switch and a time-range picker. Teachers can toggle the setting on or off and select either time to customize the assessment access window.

  • When the setting is on, teachers can select either time to customize the assessment access window.
  • When the setting is off, the time-range picker buttons are disabled and do not open the time picker.

Time picker behavior

The picker prevents invalid ranges rather than correcting them after the fact, reusing the min / max pattern already in DatePicker.vue:

  • The Start picker greys out and disables every time at or after the End time.
  • The End picker greys out and disables every time at or before the Start time.
  • A 30-minute minimum window is enforced, so a zero-length range (e.g. 7:00 AM – 7:00 AM) can't be set.
  • As a safeguard, Save still validates that End is after Start; if it isn't, saving is blocked rather than storing an invalid window.

Mockup · Student App, Assignments

If a student opens the Assignments tab outside of the approved Monday–Friday school hours, the assessments appear greyed out and can't be started. Lessons remain available as usual.

In this example, the two assessments — Print Concepts and Vowel Sounds — are dimmed because it's outside the access window.

Edge Cases

  • Mid-session window close: If a student is inside an assessment when 3 PM hits, let them finish the current assessment and block new ones.
  • Interaction with “Assignments-first”: If a class has both “Show students Assignments first” and “Limit assessment access” turned on, a child could open the app outside school hours and find that their only assigned work is assessments — which are locked. Without a fix, they’d be trapped on the assignments screen with nothing they’re allowed to tap.
    When outside school hours:
    • If the student’s only remaining assignments are locked assessments, the app should allow normal free play.
    • Assessment tiles still appear greyed out, and tapping one shows the “only available during school hours” message.
