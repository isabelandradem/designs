New Assessments Tab in Teacher Library

Jira Ticket: KKIDS-8488

Current experience

The Teacher Library currently has 9 tabs.

During the pilot, teachers could access assessments from the Reading and Math tabs.

Open question for beta launch: For the beta launch, do we want teachers to be able to preview and assign assessments from the app? Or should we limit access to assessments to the Web Dashboard?

Pros

  • Teachers can test the assessment from their devices.
  • Consistent functionality for assessments & learning activities.

Cons

  • Requires a significant change to the app UX.

For SY26–27, we were planning to make assessments available only through the Web Dashboard.

Challenge

Today, learning activities are available in both places: the app and the Web Dashboard. If assessments are only available on the Web Dashboard, they would work differently from other activities.

There’s also one key gap: teachers can watch assessment videos in the Web Dashboard, but they can’t try the assessments in the app.

Open question: Toggle or no toggle?

Some assessments start at the 2YO level, while others start later.

A toggle could help teachers hide assessments that are too advanced for their students. However, this may be harder for Engineering to build. We’d also need to make sure the toggle matches the Assignments page on the Web Dashboard.

A no-toggle version would be simpler for now.
