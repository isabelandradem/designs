How it works

In a DD1SlotPerItem question, the screen has one or more drop slots, and the child drags items into them. The defining behavior: each drop slot can hold only one item. Each Valid item is paired with an accepted drop slot number, so this is an item-to-drop-slot matching task.

The one rule that defines DD1SlotPerItem

Each drop slot holds exactly one item. The moment an item lands in a drop slot, that slot is full. Each Valid item is tagged with the accepted drop slot number(s): "slot": "1" (only slot 1) or "slot": "2,3" (slot 2 or 3).

The big question: how is this different from DDXintoA?

This trips a lot of people up — and with a single drop slot the two types look and behave identically. The difference only becomes visible when there are two or more drop slots:

DDXintoADD1SlotPerItem
The mental model One accepted drop slot group that collects Valid items. A set of drop slots, each matched to one Valid item.
Items per drop slot A drop slot can hold many Valid items (up to its target count). A drop slot holds exactly one item, then it’s full.
What slot means on a Valid item Which target it goes in (e.g. "drop1"); several items can share the same target. The accepted drop slot number(s) (e.g. "1" or "2,3"); each drop slot still takes only one item.
Typical use Drag all Valid items into the same drop slot group. Match each Valid item to its assigned drop slot.

In plain terms

If you have one drop slot, it doesn’t matter which of the two types you pick — they behave the same. If you have several drop slots and each one should end up with a single item, that’s when you want DD1SlotPerItem.

Good to know: the comma-slot shorthand

A Valid item can list several drop slot numbers at once, like "slot": "1,2,3,4". When the picture/text is the same, this is a shortcut that creates one draggable copy per drop slot, and each copy is accepted in any of those drop slots. You’ll see this in the examples below. (The same trick works for Drop items, e.g. "slot": "drop1,drop2,drop3".)

3.1 One valid drop slot for each item

The cleanest one-to-one case: every Valid item has its own single drop slot. Item A only fits drop slot 1, B only fits drop slot 2, and so on. Each Valid item gets a single slot number, and each drop slot accepts exactly that one item.

Each uppercase letter has its own drop slot — A→1, B→2, C→3, D→4 — so there’s exactly one accepted drop slot per item. The lowercase letters (stat1–stat4) are the labels that tell the child which pan is which, and the pan art covers all four drop slots.

3.2 Several identical items into several interchangeable drop slots

When the items are all the same, any of them can go in any of the valid drop slots. One Valid line with a comma-slot list creates several identical copies, and each copy is accepted in any of those drop slots — but each drop slot still holds only one.

3.3 Different items, each valid in its own set of drop slots

A mix of the two ideas above: some Valid items belong in one specific drop slot, while others are valid in a small set of drop slots. Here one item type maps to a single slot and another maps to two interchangeable slots.

The moose is "slot": "1" — only drop slot 1 accepts it. The duck is "slot": "2,3", which creates two ducks that are each accepted by either drop slot 2 or drop slot 3. The shown part of the pattern (moose, duck, duck) is built from Static items.

3.4 Only some of the drop slots are valid

The layout may show more drop slots than there are Valid items. Only the drop slots you mark as valid will accept items; the extras don’t count. This is how a measuring task works — the child fills only up to the right amount.

The measuring strip has room for many turtles, but the content only marks three valid drop slots (drop1–drop3) — Sandy’s height. The turtle Valid line "slot": "1,2,3" makes three turtles, each accepted in any of those three drop slots. Drop a turtle anywhere else and it won’t stick.

Quick recap

3.1 one item ↔ one drop slot · 3.2 identical items into interchangeable drop slots · 3.3 different items, each valid in its own drop slot(s) · 3.4 more drop slots on screen than valid ones. Across all four, the constant is: each drop slot holds exactly one item.
