How it works

DDAnyBoxes shows a set of drop slots and usually identical items. The child drags items into the drop slots and taps the green button to check. Two things make it special:

  • Any item can go in any drop slot. Unlike DDBoxes, an item isn’t matched to one drop slot.
  • It grades by which drop slots are filled, not by which item is in which slot. The answer is right when every Valid slot is filled and every Bogus slot is empty.

The one rule that defines DDAnyBoxes

It’s about counting, not matching. The child chooses how many drop slots to fill (and which ones). The items themselves are usually interchangeable, so it never matters which block lands in which drop slot.

vs DDBoxes

DDBoxes / DDFillBoxesDDAnyBoxes
The task Put each Valid item in its accepted drop slot. Fill the Valid drop slots; leave the Bogus drop slots empty.
How it’s graded Accepted item in the accepted drop slot. Valid slots filled + Bogus slots empty. Item identity is ignored.
Can you drop into a Bogus slot? No — only accepted drop slots accept an item. Yes — any drop slot accepts an item, even one that should stay empty.
Item size in drop slot Resizes to fill the drop slot (same as DDFillBoxes)
Typical use Spelling, sorting, sequencing. Measuring / counting (“how many?”).

How Valid and Bogus work here

In DDAnyBoxes, Valid and Bogus don’t describe individual draggable pieces so much as they label the drop slots. Valid’s slot list is the set of drop slots that must end up filled; Bogus’s slot list is the set that must stay empty. The blocks the child drags are usually all the same picture.

7.1 Measure with blocks

A measuring task: “How many blocks tall is the boy?” There’s a vertical stack of 4 drop slots next to the boy, who is 3 blocks tall. The child drags blocks into the drop slots to measure him — the answer is correct when the bottom 3 drop slots are filled and the top drop slot stays empty.

Why not DDBoxes here?

With DDBoxes each drop slot wants a specific Valid item, which makes no sense when every block is identical and the real question is “how many?”. DDAnyBoxes lets the child drop blocks freely and grades the count — the Valid drop slots filled, the Bogus drop slots empty.
