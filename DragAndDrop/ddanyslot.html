How it works

In a DDAnySlot question, the screen has a few drop slots and some draggable items. The child drags Valid items into the drop slots, and it doesn’t matter which Valid item goes in which drop slot. Each drop slot still holds only one item.

The one rule that defines DDAnySlot

There is no item-to-slot match. Any Valid item is accepted by any drop slot. The task is about filling drop slots, not matching each item to a specific slot.

How is this different from DD1SlotPerItem?

These two look similar — both put one item per drop slot — but they grade the child completely differently:

DD1SlotPerItemDDAnySlot
Does it matter which item goes where? Yes — each Valid item has an accepted drop slot. No — any Valid item can go in any drop slot.
The task Match each Valid item to its drop slot. Fill the drop slots (placement is irrelevant).
slot on a Valid item Has a slot number, e.g. "1" or "2,3". Left blank — no assigned drop slot.
Graded on Correct item-to-drop-slot pairing. Getting Valid items into the drop slots.

The quickest way to tell them apart

Look at the Valid items. If they carry a slot value, it’s a matching task (DD1SlotPerItem). If they have no slot, any Valid item fits anywhere (DDAnySlot). In both, Bogus items are never accepted into a drop slot.

4.1 Valid items are accepted by any drop slot

Several items, a few drop slots, and any Valid item can fill any drop slot. The child just needs to get a Valid item into each drop slot. Notice the Valid items have no slot — that’s what makes placement free.

The single Valid line offers four hats, none with a slot — so any hat is accepted on either animal. There are two drop slots to fill (numValidItems: 2: the cat on drop1, the dog on drop2), and numExtraItems: 2 means extra hats are offered so the child has a choice. Compare this to DD1SlotPerItem, where each hat would have an assigned drop slot.

Quick recap

DDAnySlot = fill every drop slot, any Valid item works. The giveaway is Valid items with no slot. If which-item-goes-where matters, you want DD1SlotPerItem instead.
