How it works

DDLetterBoxes shows a row of empty drop slots and a set of Valid text items (single letters or letter chunks like er). The child drags the text items into the drop slots to spell the target word, then taps the green button to check.

  • The draggable items are text, not pictures. You type the letters right in the JSON; the app draws them as draggable text items.
  • Order is what matters. The answer is correct when the text items, read left-to-right, spell the target word. A text item is not tied to one specific drop slot unless the order requires it there.
  • Each drop slot holds one text item, and the slots fill left to right.

The one rule that defines DDLetterBoxes

It grades the spelling, not the placement. The app reads the letter sounds in the order they were placed and checks whether they spell the word — which is why this type is built for letters and word-building.

8.1 Spell “herd”

The child sees a picture of a herd of animals and three drop slots, with the text items h, er, d below. They drag the items into the slots in order to spell herd — note er is a single text item, teaching that two letters can make one sound.

Spell the word: herd (h · er · d) LetterBoxes.leaf.json · q1 (3–61)

A picture of a herd above three empty drop slots, with the text items h, er and d in the tray. The child orders them to spell the word.

{
  "name": "q1",
  "questionType": "DDLetterBoxes",
  "layout": ".../LetterBoxes3Image",
  "var1": "herd",
  "var2": "h",
  "var3": "er",
  "var4": "d",
  "numValidItems": 3,
  "numTotalItems": 3,
  "comments": "spell h-er-d",
  "items": [
    { "itemType": "Background", "path": ".../plantaseed.png" },
    { "itemType": "Static", "path": ".../Words/{var1}.png", "audioPath": ".../Words/{var1}_word.mp3", "slot": "stat2" },
    { "itemType": "Static", "path": ".../DDBoxes/junglelightgreen3box.png", "slot": "stat1" },
    { "itemType": "Valid", "text": "{var2},{var3},{var4}", "slot": "1,2,3", "audioPath": ".../{var2}phonics,{var3}phonics,{var4}phonics", "params": "itemsInOrder=true" },
    { "itemType": "Instruction", "text": "Spell the word. {var1}." },
    { "itemType": "Yay",  "text": "{currentOrder()}. that makes. {var1}. The letters e and r sometimes make the er sound..." },
    { "itemType": "Oops", "text": "Oops! This spells. {currentOrder()}. Try again." },
    { "itemType": "ThisIsHow", "text": "This is how you spell the word. {var1}..." }
  ]
}
One Valid entry defines all three text items: text: "h,er,d" with slot: "1,2,3" sets the accepted left-to-right order, and itemsInOrder=true means the spelling is graded by that order. The two Static items provide the herd picture (stat2) and the drop slot graphic (stat1). The feedback uses {currentOrder()} so Kodi can read back exactly what the child spelled — right or wrong.

Why a “Boxes” type, but graded differently

DDLetterBoxes looks like DDBoxes (a row of drop slots the child fills), but instead of checking item-to-drop-slot matches, it checks whether the text items in order spell the word. That’s what makes it the go-to type for spelling and word-building.
