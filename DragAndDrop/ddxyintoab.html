How it works

In a DDXYintoAB question there are two drop slot groups: drop1 and drop2. Each Valid item belongs in one of those groups. Bogus items belong in neither group.

The one rule that defines DDXYintoAB

There are exactly two accepted drop slot groups. Each Valid item is tagged with "slot": "1" (belongs in drop1) or "slot": "2" (belongs in drop2).

DDXintoA vs DDXYintoAB

If you already read the DDXintoA guide, this is the only change to keep in mind:

DDXintoADDXYintoAB
Drop slot groupsOne accepted groupTwo accepted groups (drop1 & drop2)
The taskDrag Valid item(s) into one group.Sort Valid items into group 1 or group 2.
Item slotThe accepted drop slot (e.g. drop2)"1" or "2" — which drop slot group accepts it

Key fields you’ll set

FieldWhat it does
questionTypeAlways "DDXYintoAB" for this type.
layoutThe visual template — where the two drop slot groups and the tray sit.
behaviorStyleOptional special container, e.g. "Fishbowl" or "ToyBox" (two drawers).
numTotalItemsHow many draggable items appear in total.
numValidItemsHow many Valid items need to be sorted into a drop slot group.
soundExtWhich audio version plays on tap, e.g. "_word", "_phonics", "_silent".

The two-slot wiring, in plain terms

A Valid item’s "slot": "1" or "2" says which drop slot group accepts it. The groups themselves are built from a Drop plus a Static or Custom picture sharing drop1 / drop2. One Valid entry can list several pictures separated by commas — they all belong to the same group.

Item types inside items

itemTypeMeaning
ValidA draggable item accepted by one drop slot group. "slot": "1" → drop1, "slot": "2" → drop2.
BogusA draggable item accepted by neither drop slot group.
StaticA fixed picture — usually drop slot art / label, placed on drop1 or drop2.
DropDefines a drop slot group itself (its position/size).
CustomA special interactive container (e.g. a fishbowl with colored water).
BackgroundThe full-screen background image.
InstructionWhat Kodi says/asks.
Yay / OopsThe correct / incorrect feedback (text + audio).

2.1 Sort two groups — each group into its own drop slot

Every item on screen is Valid. One group of Valid items goes into drop1, and the other group goes into drop2. Here numValidItems equals numTotalItems because everything gets sorted.

2.2 Valid items into two drop slots — with Bogus items

Same two drop slot groups, but now the tray also contains Bogus items that don’t belong in either group. The child has to sort the Valid items into their groups and leave the Bogus items behind. so numValidItems is smaller than numTotalItems.

  "name": "q2",

    { "itemType": "Valid", "text": "p", "slot": "1", "textColor": "645B83", "scale": "90%" },
    { "itemType": "Valid", "text": "d", "slot": "2", "textColor": "645B83", "scale": "90%" },
    { "itemType": "Bogus", "text": "a,m,j,b,c,s,x,i,l", "textColor": "645B83", "scale": "90%" },
    { "itemType": "Background", "path": ".../earthdaytundra.png" },
    { "itemType": "Static", "text": "p", "slot": "drop1", "bgPath": ".../polarbear.png",
      "audioPath": ".../polarbear_word.mp3", "params": "bgScale=85%" },
    { "itemType": "Static", "text": "d", "slot": "drop2", "bgPath": ".../deer.png",
      "audioPath": ".../deer_word.mp3" },
    { "itemType": "Instruction", "text": "Drag the letter P to the polar bear. Drag the letter D to the deer." }
  ]
}
The “p” is "slot": "1" (polar bear on drop1) and the “d” is "slot": "2" (deer on drop2). The Bogus entry holds a comma-separated list of Bogus letters (a, m, j, …) that belong in neither group. Each drop slot is a Static letter sitting on its animal picture (bgPath).

Quick recap of the two shapes

2.1 all items are Valid and sorted into one of two drop slot groups · 2.2 sort the Valid items and leave the Bogus items behind. In both cases there are exactly two accepted drop slot groups — that’s what makes it DDXYintoAB.
