Drag & Drop Question Types

Choose the questionType that matches how items, drop slots, Valid items, and Bogus items behave.

Family 1

Slot-Based Drags

Use these when items are dragged into one or more drop slots on the screen.

DDXintoA One drop slot group: drag the Valid item(s) into the matching drop slot.

Use this when Valid items all belong in the same drop slot or drop slot group.

Good for

  • Choose the item that rhymes with a word and drag it to the drop slot.
  • Drag all items from one category, like fruit, into the same drop slot.
  • Drag a requested number of items into one drop slot, like one toy into a bowl.

Avoid this when Valid items need to be split across two drop slot groups or matched one-to-one with slots.

Open full guide
DDXYintoAB Two drop slot groups: sort Valid items into A or B.

Use this when each Valid item belongs in one of two drop slot groups.

Good for

  • Sort letter items by beginning sound into two character drop slots.
  • Sort picture items into two categories, like animals that live on land vs. in water.
  • Sort people or objects into two labeled drop slot groups.

Avoid this when there is only one drop slot group, or when each item needs its own specific drop slot.

Open full guide
DD1SlotPerItem One item per drop slot: match each Valid item to its drop slot.

Use this when each drop slot can hold one item and the item-to-slot match matters.

Good for

  • Match uppercase letters to lowercase letters in separate drop slots.
  • Complete a pattern where each next item has a specific drop slot.
  • Fill only the drop slots that match a measured height or length.

Avoid this when any Valid item can fill any drop slot. Use DDAnySlot for that.

Open full guide
DDAnySlot Any Valid item can fill any drop slot.

Use this when the child just needs to fill the available drop slots.

Good for

  • Give hats to two characters when any hat can go on either character.
  • Fill a set number of open drop slots with interchangeable items.
  • Let the child choose from extra items when any Valid item works.

Avoid this when the answer depends on which item lands in which drop slot.

Family 2

“Boxes” Drags

Use these when items are placed into a row of Boxes-style drop slots, then checked.

DDBoxes Match Valid items to specific Boxes-style drop slots, then tap to check.

Use this when each drop slot has a specific Valid item or set of acceptable Valid items.

Good for

  • Copy a visual pattern into a row of drop slots.
  • Put story pictures in order from left to right.
  • Choose the correct sound or image item for each drop slot, then submit.

Avoid this when all Valid items are interchangeable, or when the only difference is that items should resize to fill the drop slot.

Open full guide
DDFillBoxes Like DDBoxes, but dropped items resize to fill the drop slot.

Use this when you want DDBoxes behavior with cleaner, uniform sizing.

Good for

  • Drop an item onto a ruler so it lines up with the measurement marks.
  • Place differently cropped story panels into same-size drop slots.
  • Make image items snap neatly into frames or panels after drop.

Avoid this when the item should keep its original size after it is dropped.

Open full guide
DDAnyBoxes Fill the correct drop slots; item identity does not matter.

Use this when the child decides which drop slots should be filled and which should stay empty.

Good for

  • Measure a character by filling the correct number of block drop slots.
  • Show how many units tall or long something is with identical items.
  • Fill the Valid drop slots while leaving extra Bogus drop slots empty.

Avoid this when each drop slot needs a specific Valid item. Use DDBoxes instead.

Open full guide
DDLetterBoxes Spell a word by placing text items in drop slot order.

Use this when the answer is a word built from letter or letter-chunk items.

Good for

  • Spell a word by placing letter items in order.
  • Build a word from letter chunks, like h + er + d.
  • Practice blending sounds where the final answer is the ordered text items.

Avoid this when the child is matching image items into drop slots instead of spelling a word.
